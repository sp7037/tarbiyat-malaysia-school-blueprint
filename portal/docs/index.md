<h2 class="home-section-title">What this architecture combines</h2>
<p class="home-section-lead">
  Summary drawn only from the approved Concept Constitution and founding ADRs — not new decisions.
</p>

<ul class="pillar-list">
  <li><strong>Foundational academic learning</strong> — Knowledge Studios, theory, languages and mathematics practice retained where pedagogically appropriate (Lab-First, not lab-only).</li>
  <li><strong>Lab-First / Mission-Based learning</strong> — investigation, design, production and real missions organise substantial learning (ADR-0002).</li>
  <li><strong>Progressive student development</strong> — Explore → Discover → Choose → Deepen → Produce; exploration before strong specialisation (FND-003; ADR-0004 under review).</li>
  <li><strong>Six Worlds exploration and later specialisation</strong> — broad exposure precedes Major + Minor pathway depth (FND-003; maps still open).</li>
  <li><strong>Proof of Capability</strong> — parallel capability assessment layer; does not replace statutory requirements (ADR-0003).</li>
  <li><strong>Formal recognition requirements</strong> — Formal Recognition Layer remains where required by the country of implementation (ADR-0003).</li>
  <li><strong>Country-specific implementation layers</strong> — Core Educational Model separated from Country Implementation Profiles (ADR-0001); Malaysia is the first focus.</li>
</ul>

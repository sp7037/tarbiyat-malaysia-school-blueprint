## Architectural chain

Tarbiyat Missions are not ordinary classroom projects. Where architecture permits:

**Mission → Educationalisation → Supervised production / Campus Live Workflow → Evidence → optional Deployment**

External collaboration is governed, not open-ended:

**External partner → Mission Partner Governance (Education-First) → controlled learner access → IP / data safeguards**

Education-First remains governing. Real workflow is not the same as commercial work. Partner feedback is not educational authority. Partner participation is not automatic access to learner data or IP.

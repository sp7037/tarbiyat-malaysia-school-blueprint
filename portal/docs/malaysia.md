# Malaysia

<p class="present-lede">
  The Tarbiyat Core Educational Model is country-neutral.
  Malaysia is the current first country implementation focus.
</p>

::: tip Authority
This page does **not** claim ministry approval, accreditation, licences, regulatory acceptance or government endorsement.
Unresolved Malaysian regulatory and mapping questions live in the Blueprint country profile and Gap Register.
:::

## Core vs country

| | Belongs in |
|---|---|
| Pedagogy, learning architecture, pathway logic, assessment philosophy, mission/production model | **Tarbiyat Core** |
| Statutes, boards, languages, national identity content, industry priorities, local licensing research | **Malaysia Implementation Profile** |

Core already treats boarding/residential format and sovereign data-centre architecture as **country/project choices**, not automatic universal mandates.

## What is being prepared

Documentation work for Malaysia currently includes:

- a DRAFT section guide and implementation-profile skeleton
- DRAFT Country Path research (`MY-003`) mapping plausible Act 550 / MOE school categories — **no path selected**; not a licence
- DRAFT regulated-people mapping (`MY-002`) — **not closed**
- open research gaps that must be answered with citations, not invention
- clear separation so Malaysian detail does not silently rewrite Core architecture

## What is not claimed here

- Ministry or agency endorsement
- Completed licensing or establishment approval
- Selected school category (private / international / government / other)
- Settled national/board examination mapping
- Decided ownership or governance model (Concept Note “government-owned” remains a **proposal**)
- Decided day-school vs residential model
- Invented partnerships or MOUs

## Purpose

State how Tarbiyat differs from conventional classroom-dominant schooling **as design intent**, without unverified “world first” claims.

## Proposed differentiators (DRAFT)

| Differentiator | Conventional default (simplified) | Tarbiyat Core intent |
|---|---|---|
| Organising unit | Subjects/periods as centre | Missions + labs/studios as centre |
| Practical work | Often demonstration/confirmation | Production, investigation, real outputs |
| Theory | Often primary delivery mode | Tool for mission accomplishment; direct teaching when needed |
| Recognition | Exams as sole narrative of worth | Exams as safety/recognition layer + Proof of Capability + portfolio |
| Specialisation | Early streaming / labels | Broad exposure then Major + Minor |
| Spaces | Classroom-centred campus | Lab/studio/workshop-centred; Knowledge Studios for briefing/seminar |
| External reality | Occasional visits/talks | Real missions; Industry-in-Residence |
| Enterprise | Usually extracurricular | Supervised IP / Mission-to-Market pathways (policy-bound) |

## Claim hygiene

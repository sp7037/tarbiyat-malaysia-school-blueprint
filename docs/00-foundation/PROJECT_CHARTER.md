## 1. Project name

**Tarbiyat Malaysia — Lab-First Mission School & College**

## 2. Intent (DRAFT)

Create a version-controlled blueprint for a Lab-First, Mission-Based school and college model whose educational experience is organised around missions, laboratories, studios, workshops, projects and real problems, while retaining recognised national/board examinations as the formal recognition and academic safety layer.

Initial intended implementation country: **Malaysia**. Core model IP remains country-agnostic.

## 3. In scope

- Core educational architecture and project IP documentation
- Malaysia Implementation Profile (separate layer)
- Evidence, claims, decisions and implementation planning artefacts
- Controlled use of Oman and other historical proposals as reference sources

## 4. Out of scope (Iteration 0 / until approved)

- Complete curriculum maps, staffing rosters, budgets, site selection
- Invented Malaysian legal/regulatory pathways
- Automatic adoption of Oman-specific assumptions

## 5. Success criteria for documentation programme

- Clear Core vs Malaysia separation
- Traceable decisions (ADRs)
- Claims backed by evidence IDs or marked unverified
- Human-reviewable incremental drafts

## Purpose

Explain what kinds of environments Tarbiyat needs to operate as Lab-First, Mission-Based schooling — and what may be shared, externalised or phased — **without** a building plan, cost estimate or country compliance schedule.

---

## Core idea in one paragraph

A Tarbiyat campus is a **governed system of learning environments**, including on-site flexible Knowledge Studio / Mission spaces, mentoring and critique settings, basic production support, safeguarding/visitor controls, formation access, and a **governed external network**. Six Worlds do **not** require six laboratories. Facility intensity is capacity-coupled and anti-theatre. A **Minimum Viable Tarbiyat Campus** is functional, not flagship capital.

---

## Facility families (summary)

| Family | Examples of functions |
|---|---|
| Knowledge | Studios, seminar, quiet/independent learning |
| Mission | Flexible labs; making; science; digital; creative; food/agri/environment; civic/human systems |
| People / development | Mentoring, pathway dialogue, critique/defence, practitioner prep, staff collaboration |
| Production / support | Storage, tools, IT charging, preparation, documentation/display, logistics |
| Safeguarding / control | Controlled-access zones, visitor interface, sightlines, secure storage, sensitive-data work, first-aid interfaces |
| Formation / wellbeing | Physical development, recreation, reflection, community interaction |
| External learning | Community, workplace, university/research, industry, field, cultural/civic |

## Classification shortcut

| Class | Meaning |
|---|---|
| **A Essential** | Engine cannot launch without the **function** |
| **B Shared** | One adaptable environment serves many modes/Worlds |
| **C External** | Governed partner/network access is legitimate |
| **D Expandable** | Add as pathways and capacity mature |
| **E Country-dependent** | Local statute/recognition/residential rules |

---

## Minimum Viable Tarbiyat Campus (functional)

Flexible Knowledge/Mission environments + safe specialist access (on-site and/or external) + mentoring/critique + basic support & safeguarding controls + formation access + governed external network.

No room counts or square metres are Core law.
